# Rain

Given a list of non-negative integers representing the heights of walls
with unit width 1, calculate how many square units of water are retained
after it rains.

## Files

* `0-rain.py`: defines `rain(walls)`, which returns the total amount of
  rainwater retained. The ends of the list retain no water, and an empty
  list returns `0`.

## Requirements

* Python 3.4.3 on Ubuntu 14.04 LTS
* PEP 8 style, no imported modules
* All files are executable and end with a new line

## Usage
$ ./0_main.py
6
6
