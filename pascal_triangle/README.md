# Pascal's Triangle

## Files

* `0-pascal_triangle.py`: defines `pascal_triangle(n)`, which returns a
  list of lists of integers representing Pascal's triangle of `n`.
  Returns an empty list if `n <= 0`.

## Requirements

* Python 3.4.3 on Ubuntu 14.04 LTS
* PEP 8 style
* All files are executable and end with a new line

## Usage
$ ./0-main.py
[1]
[1,1]
[1,2,1]
[1,3,3,1]
[1,4,6,4,1]
